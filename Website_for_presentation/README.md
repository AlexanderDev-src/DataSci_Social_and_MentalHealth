# เว็บนำเสนอผลโครงงาน

สไลด์นำเสนอแบบเว็บของโครงงาน "การศึกษาความสัมพันธ์ระหว่างพฤติกรรมการใช้โซเชียลมีเดียกับสุขภาวะทางจิตของนักศึกษา"
ทุกสไลด์ที่มีกราฟปรับค่าได้ระหว่างนำเสนอ เช่น เลื่อนค่า r ดูจุดกระจาย เลื่อนตัวแปรในสมการถดถอยดูคะแนนที่ทำนาย
หรือสลับรวมผู้ไม่ผ่านข้อดักดูว่าค่า p ข้ามเส้น 0.05 หรือไม่

Astro 7, React 19, TypeScript ไม่มีไลบรารีกราฟ กราฟทุกตัววาดด้วย SVG เอง

## วิธีรัน

```bash
npm install
npm run dev        # http://localhost:4321 แก้โค้ดแล้วหน้าเว็บรีโหลดเอง
npm run build      # สร้างไฟล์ไว้ใน dist/
npm run preview    # เปิดไฟล์ใน dist/ เหมือนตอนใช้จริง
npm test           # เทสต์ฟังก์ชันสถิติเทียบกับตัวเลขในรายงาน
npm run check      # ตรวจชนิดข้อมูลทั้ง .ts .tsx และ .astro
```

ฟอนต์ติดตั้งผ่าน npm (Noto Sans Thai และ Sarabun) จึงใช้งานได้แม้ห้องนำเสนอไม่มีอินเทอร์เน็ต

## ที่มาของตัวเลข

ข้อมูลรายคนอยู่ใน `codingpy/data/` ซึ่งไม่ถูก commit เว็บจึงไม่ได้อ่านข้อมูลรายคนเลย

- `src/data/generated/aggregates.json` เขียนโดยหัวข้อ 12 ของ `codingpy/social_media_mental_health.ipynb`
  มีเฉพาะค่าสถิติรวม ได้แก่ สหสัมพันธ์ สัมประสิทธิ์และเมทริกซ์ความแปรปรวนร่วมของสมการถดถอย และฮิสโทแกรมชั่วโมงใช้งาน
  ถ้าข้อมูลเปลี่ยน ให้รัน notebook ใหม่ทั้งไฟล์จากรากของ repo
  ```bash
  cd .. && uv run jupyter nbconvert --to notebook --execute --inplace codingpy/social_media_mental_health.ipynb
  ```
- ตัวเลขที่เหลือ (ระดับความรุนแรง ANOVA ผลเมื่อรวม 121 คน การทดสอบสมมติฐาน) คัดมาจากบทที่ 4 ของรายงาน
  อยู่ในไฟล์ `src/data/*.ts` แต่ละไฟล์ระบุเลขตารางที่มา
- จุดในกราฟสหสัมพันธ์ (สไลด์คำถามข้อ 1 และ 2) เป็นจุดจำลองที่มีค่า r เท่ากับที่พบ ไม่ใช่ผู้ตอบจริง และบนกราฟเขียนกำกับไว้

## โครงสร้างโค้ด

แบ่งเป็นชั้น โค้ดชั้นในไม่รู้จักชั้นนอก

```
src/
├── domain/      สถิติและความรู้เรื่อง DASS-21 เป็น TypeScript ล้วน ไม่มี React ไม่มีข้อมูลของโครงงาน
├── data/        ผลการวิเคราะห์ของโครงงานนี้ พร้อมชนิดข้อมูล
├── shared/      ชิ้นส่วนที่หลาย feature ใช้ร่วมกัน: แกนกราฟ scale slider แท็บ การเคลื่อนไหว
├── features/    กราฟที่ปรับค่าได้ หนึ่งโฟลเดอร์ต่อหนึ่งเรื่อง
├── slides/      หนึ่งไฟล์ต่อหนึ่งสไลด์ ประกอบข้อความเข้ากับ feature
├── layouts/     โครง HTML ของทั้งหน้า
├── pages/       เรียงลำดับสไลด์
└── styles/      design token (สี ฟอนต์ ขนาดตัวอักษร) และ CSS พื้นฐาน
```

ทิศทางการ import: `slides → features → shared → data → domain`

- `domain` ไม่ import อะไรจากชั้นอื่น
- feature หนึ่งไม่ import อีก feature หนึ่ง ถ้าต้องใช้ร่วมกันให้ย้ายลง `shared` หรือ `domain`
- แต่ละ feature มี `model/` (state และการคำนวณ เป็น hook หรือฟังก์ชัน) แยกจาก `ui/` (component และ CSS module)
  และเปิดให้ใช้ผ่าน `index.ts` เท่านั้น

| feature | สไลด์ | ปรับอะไรได้ |
|---|---|---|
| `deck` | ทุกสไลด์ | เปลี่ยนสไลด์ แถบความคืบหน้า เต็มจอ สลับพื้นมืด |
| `usage-histogram` | ที่มา | (ภาพนิ่ง) จำนวนคนตามชั่วโมงใช้งาน |
| `data-quality` | ข้อมูล Kaggle | สลับ Kaggle กับข้อมูลของเรา ดูการกระจายของทศนิยม |
| `severity` | DASS-21 | เลือกระดับความรุนแรง ดูร้อยละที่อยู่ตั้งแต่ระดับนั้นขึ้นไป |
| `correlation-explorer` | ข้อ 1 และ 2 | เลื่อนค่า r หรือเลือกค่าที่พบจริง ดูจุดกระจายและ r² |
| `attention-check` | ข้อ 3 | สลับ 107 กับ 121 คน ดูค่า p ข้ามเส้น 0.05 |
| `content-groups` | ข้อ 4 | สลับความกว้างแท่งตามจำนวนคนในกลุ่ม |
| `correlation-ranking` | ข้อ 5 | เลือกมิติ ดูตัวแปรทั้งแปดเรียงตามความแรง |
| `hierarchical-r2` | ข้อ 6 | เพิ่มตัวแปรโซเชียลมีเดียเข้าสมการ ดู R² ที่เพิ่ม |
| `score-drivers` | ลองเลื่อนดู | เลื่อนตัวแปรต้นทั้งแปด ดูคะแนนที่สมการทำนายพร้อมช่วงความเชื่อมั่น |
| `effect-plot` | ข้อ 7 | เลือกตัวแปรและมิติ ดูเส้นทำนายและแถบความเชื่อมั่น |
| `finance-groups` | สภาพการเงิน | เลือกมิติ ดูคะแนนเฉลี่ยสามกลุ่ม |
| `power-analysis` | ไม่พบไม่ได้แปลว่าไม่มี | เลือกขนาดความสัมพันธ์และจำนวนผู้ตอบ ดูโอกาสตรวจพบ |
| `multiple-testing` | Bonferroni | เลื่อนจำนวนการทดสอบ ดูว่าคู่ไหนยังผ่านเกณฑ์ |

### เพิ่มสไลด์ใหม่

1. สร้างไฟล์ใน `src/slides/` ใช้ `<Slide>` จาก `@features/deck/ui/Slide.astro`
2. ถ้ามีกราฟปรับค่าได้ สร้างโฟลเดอร์ใน `src/features/` แล้วใส่ใน slot `stage` พร้อม `client:visible`
3. เพิ่มสไลด์ลงใน `src/pages/index.astro` ตามลำดับที่ต้องการ

หัวข้อสไลด์ตัดบรรทัดเฉพาะตรงช่องว่างที่เขียนไว้ในชื่อ เพราะตัวตัดคำของเบราว์เซอร์ตัดคำทับศัพท์อย่าง "โซเชียล" กลางคำ
ถ้าหัวข้อยาวให้เว้นวรรคตรงที่ยอมให้ขึ้นบรรทัดใหม่
